# ALGO-SPIRE ⚔️ 📖
> **Master Knowledge. Defeat Weaknesses.**

ALGO-SPIRE is a dark-fantasy rogue-like deck-building educational game where academic subjects become battlefields, cognitive misconceptions summon monstrous counter-attacks, and mastery unlocks hidden compressed paths and secret endgame trials.

Live Deployment: [https://ohmshrivastava66-source.github.io/ohmshrivastava66-source/](https://ohmshrivastava66-source.github.io/ohmshrivastava66-source/)

---

## 🌟 Core Features

1. **Deterministic Cognitive Diagnosis Engine**
   - Pinpoints procedural errors, sign slips, order-of-operation violations, and prerequisite gaps in real time.
   - Enemies mutate and deploy defensive counter-measures when misconceptions occur.

2. **The Echo Dungeon Vaults**
   - Dedicated interactive revision vaults (*The Factor Vault*, *CS Recursion Vault*, etc.) providing targeted remediation and step-by-step repair.

3. **Mastery Compression Hidden Path**
   - A challenging alternative to the progressive Main Path: compresses multi-concept mastery into dense, multi-step Crucible Trials.
   - Earned early boss access through demonstrated multi-concept coverage—never a simple skip.

4. **Weighted Adaptive Danger System**
   - Silent telemetry calculates a hidden Need Score that subtly tunes realm hazards (3%–18% calibrated probability) targeting student struggle areas with recency decay.

5. **Hidden Surprise Attack / Ambush System**
   - Highly observant Spire denizens detect rapid progression velocity and stage elite multi-concept ambushes with zero advance warning.

6. **The Convergence: The Final Council**
   - Secret endgame unlocked only after defeating all 8 realm bosses, featuring progressive boss rage, cross-domain synthesis trials, and council reactions.

7. **The Spire Learns You**
   - **Student Learning DNA**: 10-dimensional hidden behavioral profile tracking speed, accuracy, verification habits, recovery resilience, and adaptability.
   - **Counter-Strategy System**: Subtly adapts question presentation to counter shortcut-seeking and formula-rushing while maintaining curriculum fairness.
   - **The Observer**: Ultra-rare entity observing elegant feats, offering void challenges and a single-use "Ask Anything" prompt.
   - **Mirror Bosses**: Inverted reflections targeting student-demonstrated weaknesses with 100% progress safety upon defeat.
   - **The Last Question**: Reflective post-Convergence prompt mapping player insights into 5 philosophical ending archetypes.

8. **8 Extensible Educational Realms**
   - Mathematics, Computer Science, Physics, Chemistry, Biology, History, Geography, and Language with scalable difficulty from Primary Academy to University Advanced.

## 🛠️ Technology Stack

- **React 19 + TypeScript**: Decoupled state machines, modular screen routing.
- **Tailwind CSS v4 + Lucide React**: Dark-fantasy aesthetic, cosmic void palettes, high-contrast accessible typography.
- **HTML5 Canvas & Web Audio API**: Procedural particle simulations, spatial sound synthesis with zero external audio assets.
- **Vite**: Ultra-fast bundler configured with relative asset resolution (`base: './'`) for seamless GitHub Pages deployment.
